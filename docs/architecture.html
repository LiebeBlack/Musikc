01 / DATA PATH

Del contenedor
al driver.

La ruta lógica implementada es decoder → mapeo de representación, cuando es exacto → ring SPSC → callback de PortAudio → driver elegido. No se introduce un control de volumen digital ni un grafo DSP dentro de esa ruta.

ARCHIVO→DECODER→RING SPSC→PORTAUDIO→DRIVER

El modo exclusivo es una petición al driver, no un bypass universal del hardware. Windows, el host API y el fabricante siguen teniendo control sobre lo que sucede después de la llamada al callback.

03 / REPRESENTACIÓN

Conversión de contenedor,
no de frecuencia.

El mapeo PCM puede ensanchar una palabra cuando el destino lo exige; solo se declara exacto si conserva los bits significativos. La conversión que descarte información se rechaza salvo que el usuario habilite explícitamente el modo degradado.

24-bit packed → 32-bit wordDesplazamiento de representación. El DAC recibe un contenedor de 32 bits con los 24 bits válidos, si el driver acepta ese formato.

Los parsers nativos cubren WAV/RF64, AIFF/AIFF-C compatible, DSF y DFF sin DST. FLAC requiere libsndfile o una ruta fallback con FFmpeg. La disponibilidad concreta depende de los binarios instalados y del formato contenido.

04 / OUTPUT NEGOTIATION

La frecuencia la acepta
el dispositivo.

El motor sondea los formatos disponibles y solicita el sample rate de la fuente. Comprueba los valores que reporta el stream abierto y falla si no coinciden. Esa comprobación no puede inspeccionar internamente el firmware ni demostrar la salida analógica.

WASAPI ExclusiveHost API habitual para salida exclusiva en Windows.WDM-KSKernel streaming; disponibilidad según dispositivo y driver.ASIOSolo si la distribución PortAudio instalada incorpora soporte ASIO.Modo compartidoEl sistema puede aplicar su mezclador; no se etiqueta como ruta garantizada bit-perfect.

05 / VERDICT

Qué significa
el indicador.

El badge solo se activa cuando el motor tiene una fuente compatible, un formato de salida negociado, una ruta que considera exacta y ningún xrun registrado en la sesión actual. Se apaga cuando cambian esas condiciones.

  • BIT-PERFECT es un estado calculado por el software y dependiente de la configuración.
  • El hash BLAKE2b cubre los bytes registrados por el motor en la salida; no es una captura eléctrica de la salida del DAC.
  • Un xrun significa que el callback tuvo que completar muestras faltantes con silencio; la sesión deja de ser exacta.
  • En modo compartido, el OS mixer puede modificar o remuestrear después de la aplicación.

06 / ALCANCE

Limitaciones conocidas.

  • Windows 10/11 x64 como plataforma objetivo.
  • DoP es transporte DSD por PCM; no es salida DSD nativa del driver.
  • DST comprimido no se decodifica.
  • El soporte ASIO depende de la build de PortAudio presente.
  • No existe volumen digital, ecualizador ni normalizador.
  • El badge no inspecciona filtros de driver, firmware DAC, amplificador ni circuito analógico.
