TRANSPORTE DSD SOBRE PCM

DoP no es conversión a PCM.

Los bits DSD se empaquetan con los marcadores DoP; la frecuencia PCM de transporte es DSD ÷ 16. La ruta se usa solo si el driver acepta esa frecuencia y profundidad.

06 / PREGUNTAS FRECUENTES

Lo esencial,
sin letra pequeña.

¿Por qué no hay control de volumen?

El control digital de volumen escala muestras. Para no alterar la señal de origen, el nivel se controla en el DAC o en el amplificador.

¿El programa garantiza lo que sale físicamente del DAC?

No. Puede inspeccionar el formato que informa el driver y los bytes entregados por la aplicación. No puede observar el procesamiento interno del driver, el firmware del DAC o etapas analógicas.

¿Puedo reproducir cualquier frecuencia de muestreo?

Solo si el endpoint acepta el formato. Si no lo acepta, la aplicación comunica el error y no intenta remuestrear por software.

¿ASIO está incluido?

El programa consulta los host APIs de PortAudio disponibles en el equipo. No distribuye el SDK ASIO ni garantiza que la build de PortAudio lo incluya.

¿Qué hace falta para compilar el instalador?

Python 3.15.2 x64, las dependencias fijadas en requirements y Inno Setup 6. GitHub Actions instala Inno Setup, ejecuta pruebas y empaqueta los artefactos.
