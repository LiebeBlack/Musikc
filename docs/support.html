01 / PRIMER PASO

Recoge datos
reproducibles.

Antes de cambiar drivers, ejecuta el diagnóstico en una terminal y guarda el texto completo.

POWERSHELL
python main.py --diagnostics

El informe incluye Python, PortAudio, decodificadores disponibles, endpoints visibles y relojes que el host pudo sondear. No incluye el contenido de tus archivos.

03 / XRUN

El badge pierde
estado exacto.

Un underrun indica que el callback no recibió suficientes bytes para completar un periodo y tuvo que insertar silencio. La señal de esa sesión ya no coincide con la secuencia original.

  • Aumenta el ring buffer en preferencias si el sistema sufre pausas de CPU.
  • Cierra procesos que saturen CPU/almacenamiento y evita escanear una unidad lenta durante escucha crítica.
  • Comprueba driver, latencia y buffer en la pestaña Hardware.
  • Si el contador aumenta en un sistema inactivo, adjunta el log y el endpoint exacto en un issue.

Prioridad MMCSS y prioridad de hilo son intentos del sistema operativo; no garantizan que no haya xruns.

04 / DECODIFICACIÓN

El archivo no abre.

  • WAV / AIFF: verifica que el archivo no esté truncado. AIFF-C comprimido no compatible se rechaza.
  • FLAC: confirma que `libsndfile-1.dll` está disponible o que hay FFmpeg/ffprobe para la ruta fallback.
  • DSF / DFF: DoP necesita que el DAC acepte 24-bit PCM a la frecuencia de transporte. DST comprimido no está soportado.
  • Archivo con pérdida: la aplicación está dirigida a fuentes sin pérdida; no debe presentar formatos con pérdida como bit-perfect.

Reproduce la misma fuente en el decoder de referencia de tu elección. No compartas contenido protegido al abrir un bug; adjunta la descripción del stream y el mensaje de error.

05 / BOOTSTRAP

Python o dependencias
no coinciden.

El entorno validado es Windows x64 y CPython 3.15.2. Usa el Python del proyecto virtual, no una instalación de paquetes global.

REPARAR Y COMPROBAR
python setup_env.py --repair
python setup_env.py --check

Si un proxy bloquea el download de binarios, revisa el error exacto de setup y coloca los binarios x64 permitidos por tu política en `resources/native/`. No descargues DLLs de mirrors desconocidos.

06 / REGISTROS

Logs para soporte.

Los logs estructurados se guardan en el perfil local del usuario, en `AppData/Local/TrueHQAudio/logs`. Puedes abrir la carpeta desde el menú de la aplicación.

Antes de compartir, revisa el fichero y elimina cualquier ruta de archivo o nombre de dispositivo que consideres privado. No incluyas tu biblioteca ni tus archivos de audio.

07 / CONTRIBUIR

Un issue útil
empieza con contexto.

  • Versión exacta del programa y Windows.
  • Resultado de `python main.py --diagnostics` o versión del build congelado.
  • Host API, endpoint, modo y sample rate esperado.
  • Pasos mínimos para reproducir y resultado observado.
  • Extracto del log relevante, redactado si contiene información privada.
